# C# Grundlagen

.NET-10-Solution mit neun einzeln startbaren Übungen.

| Projekt | Inhalt |
| --- | --- |
| VariablenUndDatentypen | Datentypen anzeigen |
| EinfacheEingabeAusgabe | Begrüssung und Addition |
| FehlerFinden | Alter im nächsten Jahr |
| StringOperationen | Gross-/Kleinschreibung und Verkettung |
| Nettolohn | PAP und Nettolohn berechnen |
| CodeLesen | Ganzzahldivision |
| Grundrechenarten | Vier Rechenarten |
| InkrementierenDekrementieren | Variable erhöhen und verringern |
| Modulo | Riegelanzahl und Restgeld |

In Rider die Datei HelloWorld.sln öffnen. Jedes Projekt lässt sich separat starten.

Im Ordner dieser README:

```powershell
dotnet build HelloWorld.sln
dotnet run --project VariablenUndDatentypen/VariablenUndDatentypen.csproj
```

Die bisherigen Programme wurden in eigene Projekte verschoben. Ihre Berechnungen,
Eingaben und Ausgaben sind unverändert.
